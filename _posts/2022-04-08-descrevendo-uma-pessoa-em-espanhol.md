<p> <span>Vejamos como descrever uma pessoa (persona) em espanhol. Vamos aprender aspectos físicos e o caráter de uma pessoa abaixo:</span></p><p></p><div><a href="/assets/media/2022/04/descrevendo-uma-pessoa-em-espanhol-01-4535bd72.webp" imageanchor="1" rel="noopener noreferrer"><img alt="" decoding="async" loading="lazy" src="/assets/media/2022/04/descrevendo-uma-pessoa-em-espanhol-01-4535bd72.webp"/></a></div><br/><span><br/></span><p></p><p class="has-text-align-justify"><span>Para descrever os cabelos:<br/></span>Tiene el pelo largo / corto (Tem o cabelo comprido / curto)</p><p class="has-text-align-justify">Tiene el pelo rizado / liso / ondulado (Tem o cabelo cacheado / liso / ondulado)</p><p>Lleva una coleta (Usa rabo-de-cavalo)<br/>Una trenza (Uma trancça)<br/>Un moño (Um coque)<br/>El flequillo (Franja)<br/>Media melena (Cabelos de comprimento médio)<br/>La melena larga (Cabelos muito compridos)<br/>El pelo recogido (O cabelo preso)<br/>El pelo suelto (O cabelo solto)</p><p class="has-text-align-justify">Tiene el pelo de punta / a cepillo (Tem os cabelos espetados) / Tiene el pelo rubio. / Es rubio (a) (Tem cabelos escuros / É moreno) / Tiene el pelo castaño / Es castaño (a) (Tem cabelos castanhos / É castanho)</p><p>Tiene el pelo cano (tem os cabelos branco)<br/>Es pelirrojo(a) (tem os cabelos vermelhos)<br/>Tiene mucho pelo / poco pelo / es calvo<br/>Tem muito cabelo / pouco cabelo / é calvo</p><p><span>Para descrever os olhos:</span></p><p class="has-text-align-justify">Tiene lo ojos grandes / pequeños / saltones / hundidos (Tem os olhos grandes / pequenos / esbugalhados / fundos).</p><p class="has-text-align-justify">Tiene los ojos verdes / marrones / azules / negros / grises (Tem os olhos verdes / castanhos / azuis / pretos / acinzentados)</p><p><span>Para descrever o nariz:</span></p><p class="has-text-align-justify">Tiene la nariz aguileña / respingona / chata (Tem o nariz aquilino / arrebitado / achatado)</p><p><span>Para descrever outros aspectos do rosto:</span></p><p>Tiene pecas (tem sardas)<br/>Tiene (muchos) lunares | tem (muitas) pintas</p><p><span>Para descrever o corpo:</span></p><p>Es alto (a) | É alto (a)<br/>Es bajo | É baixo (a)<br/>No es ni alto ni bajo | Não é nem alto nem baixo<br/>Es gordo (a) | É gordo (a)<br/>Es delgado (a) | É magro (a)</p><p><span>Para caracterizar uma pessoa, em geral:</span></p><p>Es muy guapo (a) | É muito bonita (a) / É lindo (a)<br/>Es muy bonita. (Usado apenas para as mulheres) | É muito bonita / É linda<br/>Es muy/un poco feo | É muito / um pouco feio</p><p><span>Para descrever a personalidade:<br/></span>Es simpático / antipático | É simpático / antipático<br/>Es amable | É gentil<br/>Es sociable | É sociável<br/>Es agradable | É agradável<br/>Es una persona divertida / aburrida | É uma pessoa divertida/chata</p>
